Action Center: home screen prototype

←↑→↓ D-pad   Enter OK (hold for quick actions)   M Menu   Esc/Backspace Back   H Home. Click the TV if keys stop responding.

Drawn at the Shield's 960×540 dp canvas (1 px here = 1 dp, shown at 2× on the TV) with tv-material's type scale and the brief's starting geometry. Artwork is placeholder gradients, and app tiles stand in for each app's real banner. Names and titles are sample data.
